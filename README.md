# قلم (Qalam) — تطبيق ملاحظات Android

كتابة بخط اليد، تعليق على PDF، لقطة لأي منطقة + ترجمة تلقائية بالـ AI، وشات AI مع ملاحظاتك.

## التشغيل
1. افتح المجلد بـ **Android Studio** (Koala أو أحدث). رح يسوي Gradle sync ويولّد الـ wrapper لحاله.
2. شغّل على جهاز/محاكي Android 10+ (minSdk 29). الأفضل تابلت أو جهاز فيه قلم.
3. من الإعدادات (أيقونة الترس) حط مفتاح Claude API.

## الميزات
- **خط اليد (Canvas):** قلم، ماركر، ممحاة، 5 ألوان، 3 سماكات، ضغط القلم، تراجع، حفظ تلقائي.
- **تحسين الخط:** تبسيط RDP + تنعيم Chaikin يزيل الرجفة ويطلّع الخط منحني. زر "تحسين الخط" يفعّله/يوقفه.
- **PDF:** استيراد، عرض كل الصفحات، والكتابة فوقها. الخطوط محفوظة منفصلة عن الملف الأصلي.
- **لقطة:** أداة "لقطة" ← اسحب مستطيل على أي منطقة ← ترجمة / شرح / حفظ بالمعرض.
- **ترجمة تلقائية:** Claude يقرأ الصورة ويترجم (اللغة من الإعدادات، الافتراضي العربية).
- **شات AI:** يشوف أول 6 صفحات فيها محتوى (خط يد أو PDF) ويجاوب عنها.

## ما انختبر
الكود انكتب بدون ما ينعمل له build (بيئة الكتابة ما فيها Android SDK). متوقع تطلع شوية أخطاء compile صغيرة بأول sync، صلحها بسيط.

## حدود النسخة الأولى
- ما في zoom/pan، الصفحات تنعرض بعرض الشاشة.
- الشات يشوف 6 صفحات بس، ما في بحث عبر كل الملاحظات.
- مفتاح الـ API محفوظ بالجهاز؛ للنشر مرّر الطلبات عبر سيرفرك.
- PDF المحمي بكلمة سر ما بينفتح.
